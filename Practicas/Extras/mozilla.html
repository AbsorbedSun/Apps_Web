Mozilla cuenta con una comunidad global

Mozilla es una organización que trabaja para mantener Internet abierto, accesible y seguro para todas las personas.

Su comunidad está formada por personas de diferentes lugares delmundo que colaboran para mejorar la Web y promover una Internet saludable.

  • Tecnologistas
  • Pensadores
  • Constructores

Firefox es un navegador web desarrollado por Mozilla. Está diseñado para ofrecer una experiencia de navegación rápida, personalizable y centrada en la privacidad de los usuarios.
